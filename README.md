# MediaSnap v2.0 — Video & Audio Downloader

Download videos and audio from **1000+ platforms** including YouTube, Twitter/X, Vimeo, Twitch, TikTok, Instagram, Facebook, Reddit, SoundCloud, Dailymotion, and more — powered by **yt-dlp**.

---

## ✨ Features

| Feature | Details |
|---|---|
| **1000+ platforms** | YouTube · Twitter/X · Vimeo · Twitch · TikTok · Instagram · Facebook · Reddit · SoundCloud · Dailymotion · LinkedIn · Rumble · Bilibili · and more |
| **Video quality** | 4K · 1080p · 720p · 480p · 360p · Best auto |
| **Audio quality** | Best VBR · 320 / 256 / 192 / 128 / 64 kbps |
| **Audio formats** | MP3 · M4A · WAV · OGG · FLAC · Opus |
| **Subtitles** | Download subtitles in any language, auto-generated supported |
| **Thumbnails** | Save embedded video thumbnail alongside the file |
| **Bulk download** | Queue multiple URLs at once with configurable concurrency |
| **Playlist download** | Fetch entire playlists with per-item selection |
| **Scheduled downloads** | Set a future date/time — download starts automatically |
| **Desktop notifications** | Browser notification when each download completes |
| **Speed limit** | Cap download speed (e.g. `1M`, `500K`) |
| **Download history** | Search, filter, re-download, or save past downloads |
| **5 languages** | English · العربية (RTL) · Español · Français · Português |
| **Dark / Light theme** | Toggle with the ☀️/🌙 button; respects OS preference |
| **Browser extension** | Chrome/Firefox extension — send any page URL with one click |
| **Cookies/auth** | Support for private, age-restricted, and members-only content |
| **Real-time progress** | SSE streaming — live download bar, speed, and ETA |
| **Docker support** | Single `docker compose up` for containerised deployment |

## 📋 Prerequisites

| Tool | Required | Install |
|---|---|---|
| Python 3.10+ | ✅ | [python.org](https://python.org) |
| Node.js 18+ | ✅ | [nodejs.org](https://nodejs.org) |
| ffmpeg | ✅ | See below |
| Docker (optional) | — | [docker.com](https://docker.com) |

### Install ffmpeg

**Windows** (winget):
```
winget install ffmpeg
```

**macOS** (Homebrew):
```
brew install ffmpeg
```

**Ubuntu / Debian**:
```
sudo apt install ffmpeg
```
